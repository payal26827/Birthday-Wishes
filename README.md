# Birthday Surprise (React + Vite + Framer Motion)
1. npm install
2. npm run dev      (open the local/network URL, try it on your phone)
3. Edit ALL content in src/data.js (name, letter, timeline, photos, songs, wish...)
4. Photos go in public/photos/
5. npm run build -> upload the `dist` folder to Netlify Drop / Vercel / GitHub Pages and send him the link.
